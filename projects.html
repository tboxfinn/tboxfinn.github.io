Featured Project

DIG

DIG is a multiplayer mining game for up to 4 players, featuring procedurally generated levels using marching cubes technology. Each player, as a miner, must descend carefully by breaking terrain, avoiding deadly falls and overcoming unique challenges. The project is currently in development.

My Role:

Game Designer, Programmer, Multiplayer Systems

Key Features:

  • • Procedural generation with marching cubes
  • • Multiplayer for up to 4 players
  • • Terrain destruction and mining mechanics
  • • Challenging descent and hazards
Unity C# Procedural Generation Marching Cubes Multiplayer Game Design

Mutant Wastelands

Mutant Wastelands is a post-apocalyptic action roguelite featuring procedural maps, unique mutant abilities, and challenging combat. Developed in Unity, it offers dynamic environments and replayable gameplay with a variety of mutant powers and enemies.

My Role:

Game Designer, Programmer, Level Designer

Key Features:

  • • Procedural map generation
  • • Unique mutant abilities
  • • Fast-paced combat
  • • Replayable roguelite structure
