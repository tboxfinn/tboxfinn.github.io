01 — Featured Project / Action Roguelite

Mutant Wastelands

Mutant Wastelands is a post-apocalyptic action roguelite featuring procedural maps, unique mutant abilities, and challenging combat.

Problem Solved & Metrics: I developed a scalable procedural generation system capable of creating distinct layouts dynamically. This system reduced manual level design time by 80% while increasing replayability significantly.

My Role: Gameplay Programmer, Systems Engineer

  • Modular procedural map generation
  • Data-driven mutant abilities
  • Fast-paced robust combat systems

02 — Multiplayer Prototype

DIG

DIG is a multiplayer mining game for up to 4 players, featuring procedurally generated levels using voxel marching cubes technology.

Problem Solved & Metrics: Implemented a performant marching cubes algorithm for real-time terrain destruction and generation. Maintained a solid 60 FPS across network sessions while ensuring perfect synchronization of modified voxel data for up to 4 concurrent players.

My Role: Programmer, Multiplayer Systems

  • Voxel procedural generation (Marching Cubes)
  • Multiplayer networking code
  • Synchronized terrain destruction
